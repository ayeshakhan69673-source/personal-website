# 💻 Personal Portfolio Website

My developer portfolio, designed with a **chalkboard / terminal theme**. It is built with plain HTML, CSS and JavaScript, with no frameworks.

🔗 **Live site:** [personal-website-tau-swart-42.vercel.app](https://personal-website-tau-swart-42.vercel.app/)

## ✨ About

The site introduces me, my skills and my projects in a style that matches how developers work. It is hosted for free on Vercel.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Deployed on Vercel

## 🚀 Run It Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/ayeshakhan69673-source/personal-website.git
   ```
2. Open the folder and double-click **`index.html`** to view it in your browser.
